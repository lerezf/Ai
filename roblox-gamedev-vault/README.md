# Roblox Game Dev Vault

A markdown knowledge base (Obsidian-compatible) that an AI agent (Claude / ChatGPT) reads before helping with Roblox game design, development, animation, and monetization. Method from the @adamdoesrobloxx reel "Make Claude/ChatGPT learn game design."

## How it works
1. This repo is the hub. The agent reads `AGENT.md` first.
2. The agent studies top Roblox YouTube videos / official docs and writes notes into the topic folders using the template in `AGENT.md`.
3. When you ask for help on a game, the agent reads the relevant notes and `applications/` and applies the techniques.

## Map
- `AGENT.md` : instructions + note template for the agent
- `design/` : retention, first 5 minutes, core loops, replayability
- `development/` : launch, growth, algorithm, metrics
- `animation/` : tools and workflow (Moon Animator, Blender, Studio editor)
- `monetization/` : passes, dev products, Premium Payouts, pricing
- `applications/your-games.md` : how the notes map to your specific games
- `sources/` : channels and links, with confidence levels
- `queue/video-queue.md` : videos still to study (needs transcripts)

## Honesty note
Initial notes come from web write-ups, DevForum posts, official Creator Hub docs, and third-party summaries of YouTube videos. They are NOT full transcripts of the videos. Each note lists its sources. Items marked (low confidence) came from weak sources and should be verified.
